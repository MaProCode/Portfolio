CAR CLUSTER & INFOTAINMENT

Limited Edition sport car Cluster and Infotainment box

Full featured electronics development for a limited edition Sport car (Chevy Corvette C8 based), including a cluster, an infotainment and a passenger display, implementing customer design elements and functionalities.



details:

• Cluster includes accelerometer analog widget, engine map mode indication and all the classic cluster indicators.

• Infotainment has an Android Auto implementation (third party), Rear Camera, Tyre Pressure indication, HVAC driving capability via a touch screen and more.

• Passenger display is dedicated to a customized music player, and engine map settings view.

Phase 1: Idea & Research
Project Scope
This project regards the realization from the concept to the final product of the complete dashboard electronics, including a cluster, an infotainment box and a passenger display, for a limited-edition hypercar inspired by the racing prototypes of the 1970s and 80s.
The car combines extreme design with high performance and a focus on an unfiltered driving experience, and offer extensive customization possibilities to each client.
The production is limited, with only a small number of units, including a coupè and a speedster version, being made.



Preliminary activity
An on-vehicle activity, related to the CAN bus message reverse-engineering preliminary analysis was necessary, allowing us to understand and interpret a vehicle's communication network associated signals.
This was done by acquiring data both while stationary in the garage and on the road to collect dynamic data.
This leads to obtain at the end, a great part of the GM CAN bus message mapping.

Preliminary tests include as well several checks to verify the integration between the choosen electronic platform and car electrical interface.
Phase 2 - Design & UX
First operative step was PC side development of a preliminary SW for the basic functions.

CLuster realization including:
  - UI design with custom gadgets for various indicators
  - Data acquisition from vehicle CAN bus, queries on OBDII port, accelerometer sensor, external switches
  - Electric interface design to acquire analog signals from vehicle
  - Real time data display on cluster, with indication of:
    > Vehicle Speed, Engine Rpm, Odometer, Gearshift
    > Lateral Acceleration (G-force meter)
    > Engine Oil/Water Temperatures, Battery level, Fuel level
    > Indicators: low/high Light Beam, Turn indicator, Handbrake, Door Lock status
  - UART communication link with Infotainment board, to share common data
  - Custom graphical widget design for accelerometer data display, and RPM gauge needle motion

Infotainment realization including:
  - UI design and implementation including customized widgets developed for accelerometer (G-force meter) and tyre pressure indications
  - Data collection from CAN bus, accelerometer, video stream from rear camera, and HVAC drive capabilities via CAN commands
  - Android Auto external software integration, providing connectivity with a smartphone, and some of its Apps
  - Rear camera integration in the UI

Passenger display realization including:
  - UI design and implementation
  - Customized MP3 audio player development and integration on the UI
  - Engine Map indication using a dedicated widget

A Demo mode was implemented as well, for an animated presentation of the UI to the customer.
Phase 3 - Prototyping
This phase involves the porting of the SW on Target board (based on commercial HW), doing the final adjustments to adapt the UI to the touch screen display and the software to the target board embedded peripherals.

It was also the opportunity for a Boot time and performance optimization, and system parameters tweaking.
In particular, the SW architecture of HVAC setting interface has been re-designed several time to improve the global responsiveness of the air conditioning system.
Phase 4 - Testing
> In order to test the communication link and the UI responsiveness to the CAN bus messages related to the vehicle status, a Vector CANalyzer has been used, implementing a CAPL program that simulated both, the GM CAN bus protocol, and the OBDII queries.
This networks simulation revealed to be useful, especially in the preliminary SW development phase, to proceed "off-line" without having the need of the continuous car availability for the connection to the CAN networks.

> With the increase in implemented functionalities and monitored signals, the messages traffic on the network has also increased. To continue having a realistic responsiveness of the user interface, it became necessary to switch from the CANalyzer simulated bus to an ad-hoc hardware programmed specifically for a more realistic simulation of the car's data networks.

> In this way, the tests done by connecting directly to a vehicle have drastically decreased, and were performed only occasionally to validate what has already been tested with the data network simulators.

Phase 5 - Final Result
Final phase regards "on the road testing" for the final parameter tuning and bug-fixing, validating the project in the real environment according to a test case scheme.

Phase 6 - Ares S1 on media
The ARES S1 is a limited-edition supercar by the Italian coachbuilder ARES Modena. It is a bespoke vehicle that combines the design language of a hypercar with the performance of a supercar. Due to it's Performance-Oriented specs, (it is powered by a powerful V8 engine), it's Exclusivity (only a small number of units are being built) and it's Distinctive Design featuring elements like a sculpted carbon fiber body and a unique silhouette, it easily drew attention among special car enthusiast audience, and motoring magazines.

It become part of the car fleet of various video games (Asphalt 9: Legend).

The car was also reviewed by several Web bloggers, in particular during an "on track" test, by Drive Up, a motor focused TV Show, and by by SuperCar Blondie, an automotive blogger, that posted several videos on Youtube about this car.
In some of these videos, the customized cluster / infotainment is well visible in action.
