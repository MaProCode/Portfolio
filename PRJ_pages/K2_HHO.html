AUTOMOTIVE TOOL GUI

Interactive GUI with logic for an Automotive tool


The Application is designed authorize the utilization of the device, granting a tool usage time according to a activation passwords.
Device perform data acquisition and display of system temperatures, pressures, and remaining usage time.

details:

- UI and logic design according to customer requirements, and its implementation on commercial HW.
- Anti-tampering feature: Functionalities disable when the device case is open.
- Extra time accreditation via password generated by an external Desktop sw tool provided to the system manager.
- Password generator desktop application developed in VB.NET language.

Phase 1: Application Scope
This project regards the realization of an electronic device used to drive and manage the usage of an HHO generator for diesel engines.
HHO Generator uses electrolysis to produce a mixture of hydrogen and oxygen (HHO) from water, which is then fed into the engine's air intake. Diesel engine carbon cleaning removes harmful carbon deposits from the engine, improving performance, fuel efficiency, and emissions output. It's especially beneficial for high-kilometre or stop-start vehicles.


Potential benefits:
  - Improved fuel economy: Some sources claim that HHO can lead to a 20-30% increase in fuel economy for diesel engines.
  - Reduced emissions: The improved combustion can lead to lower emissions of pollutants like carbon monoxide (CO).
  - Engine cleaning: The process may help remove carbon deposits from the engine, leading to cooler running temperatures and longer engine life.
Phase 2 - Design & UX
The preliminary software development was conducted on a PC, implementing the graphical interface with the various temperature and dispensing pressure indicators for operation monitoring, and the core software for data acquisition and the various functions intended for the HHO device's operation.
A specific UI page was also included for password entry via touch screen to extend the device's operating time, by purchasing a code from the system manager.

Phase 3 - Password Generator Tool
System Manager was then provided with a SW application for PC, to generate usage extra time passwords.
To make the password assignment non-reusable on other HHO devices, we relied on the MAC address of the device's LAN network card itself, thus making the password valid only for that specific device.
A coding rule (shuffle) was then implemented to generate a code containing a MAC address validation and which integrates the extra time allocated for the specific device's usage.
The Password Generator was implemented in Visual Basic.NET for compatibility reasons with the majority of PCs running Windows.
Phase 4 - Prototyping
The final phase involved porting the software onto the target board, and the verification and validation of:
  - the implemented functionalities, such as the enablement of dispensing;
  - the correctness of the acquired data (temperature, pressure, time elapsing) during operation;
  - the anti-tampering functionality;
  - and the correct interpretation of the passwords for assigning usage time.
